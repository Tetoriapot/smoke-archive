# SMOKE ARCHIVE

成人キャラクターの創作、時代考証、小道具デザインを支援する喫煙文化資料サイトです。React・TypeScript・Vite・Tailwind CSSで構築しています。バックエンド、ログイン、外部AI API、アクセス解析は使用しません。

## 起動

Node.js 22以降とpnpm 11を使用します。

```sh
pnpm install
pnpm dev
```

表示されたローカルURLをブラウザーで開きます。npmを使う場合は、`npm install`と`npm run dev`でも起動できます。依存関係を再現する場合は、収録した`pnpm-lock.yaml`を使用してください。

このPCでpnpmがPATHにない場合は、PowerShellから次のコマンドを実行できます。

```powershell
& 'C:\Users\tetor\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd' dev
```

## 検証とビルド

```sh
pnpm test
pnpm lint
pnpm typecheck
pnpm build
pnpm preview
```

`build`は型検査後に`dist/`へ本番用ファイルを出力します。テストはVitestで実行します。確認項目は[TEST_CASES.md](TEST_CASES.md)に記載しています。

## 基本操作

右上の「更新情報」で機能の更新履歴、「Help」で操作方法を確認できます。ダイアログは閉じるボタンかEscapeキーで閉じます。太陽・月のボタンには切り替え先のモードを表示し、ライト／ダークを切り替えます。初期表示はダークモードで、選んだモードは同じブラウザーに保存されます。スマートフォンでも3つの操作を表示します。

図鑑では、日本語名・原語名・本文・タグを検索できます。全角英数は半角相当に、カタカナはひらがな相当に変換して検索します。空白区切りの検索語と複数タグは、すべて一致する資料を表示します。「絞り込み」では、基準年、現行／終売／未確認、すべてのタグを指定できます。ランダム表示と資料出力には、表示中の検索結果を使います。

詳細画面では、説明ごとに「出典で確認」「出典側の説明」「未確認」を示します。人物像、職業、服装、所作、配色は創作上の提案です。実際の利用者の性格や社会共通の評価を意味しません。

逆引きは8種類の人物条件を使います。「王道」は一致する創作タグ、「ギャップ」は一致と対比、「意外性重視」は対比の条件を優先します。既知の登場年が時代の終わりより後の資料は除外します。登場年が不明な候補には確認が必要であることを示します。これは地域別の流通や法規制を保証する機能ではありません。

カードのしおりボタンでお気に入りを保存します。「比較」で最大3件を追加し、比較画面で確認できます。比較リストはタブを再読み込みすると解除されます。

設定帳には、複数の成人キャラクターを登録できます。名前、年齢、職業、性格、時代設定、喫煙具、銘柄、所作、メモを編集し、「設定を保存」で確定します。年齢は20歳以上の整数、または未設定にします。複製と削除も利用できます。保存する前の内容は、フォーム下部からJSONで退避できます。

## データ保存

設定帳とお気に入りは、同じブラウザー・同じサイトのlocalStorageに保存します。別の端末や別のURLとは同期しません。ブラウザーのサイトデータを消去すると失われるため、設定帳を定期的に書き出してください。

保存データを読み出せない場合は、自動上書きを止めます。元データを退避するボタンと、確認付きの初期化操作を表示します。容量不足などで保存に失敗した場合は、フォームの内容を保持し、エラーを表示します。

| 保存キー | 内容 |
| --- | --- |
| `smoke-archive:favorites:v1` | 資料IDの配列 |
| `smoke-archive:notebook:v1` | バージョン番号と人物設定の配列 |
| `smoke-archive:theme:v1` | JSON文字列の`"dark"`または`"light"` |

表示モードの保存に失敗した場合は、現在の画面だけ切り替えてエラーを表示します。保存値を読み出せない場合はダークモードで起動します。表示モードの切り替えは、設定帳やお気に入りの保存データを変更しません。

## インポート・エクスポート

設定帳はJSONとMarkdownで出力できます。Markdownには人が読む本文と、末尾の復元用JSONが含まれます。再読み込みは復元用JSONから行うため、本文だけを変更しても反映されません。任意のMarkdown文書を人物設定へ変換する機能はありません。

読み込むファイルは`.json`、`.md`、`.markdown`、最大2MBです。人物は合計500人まで扱えます。空ファイル、不正JSON、未対応バージョン、欠損したID・名前、不正な年齢、重複ID、想定外のMIMEを検出します。エラー時には既存の設定を変更しません。

読み込みは追加方式です。同じIDで内容が異なる場合、新しいIDを付けて別人物として追加します。同じID・同じ内容は重複追加しません。未知のJSONキーも保持します。旧データの省略された任意項目には空文字を補います。

図鑑の検索結果はCSVとJSONで出力できます。CSVはUTF-8 BOM付きで、引用符・改行をエスケープし、先頭の数式文字を無効化します。JSONには事実・創作案・出典などの全項目を含めます。図鑑データの編集・追加はソースJSONで行います。

## 収録資料と限界

初期資料は48件、所作は15件です。内訳は紙巻き15件、葉巻13件、パイプ5件、シーシャ4件、VAPE4件、加熱式3件、煙管・刻み4件です。件数にはブランド、個別製品、器具の型式が含まれますが、同一対象の重複登録は除いています。

出典を確認できる少数の資料から開始しています。100件以上への拡充は未完了です。現行状況、製造元、香味、映画・文学での使用、日本での評判などは、未確認の箇所が残っています。発売年の代わりに設計年や商標登録年を入力していません。価格・現在の流通状況は掲載しません。

各データの出典URL・確認日・確認範囲をJSONと画面に掲載しています。メーカーの宣伝上の評価は、客観的な検証結果と区別します。ブランド画像は転載せず、独自のSVGで分類を示しています。SVGは実物の形状やパッケージの正確な再現ではありません。

このサイトは喫煙を推奨せず、購入案内を行いません。すべてのたばこ製品には健康リスクがあり、電子タバコも無害ではありません。[WHOの資料](https://www.who.int/news-room/fact-sheets/detail/tobacco)を出典として掲載しています。

## 静的ホスティング

[GitHub Pages版](https://tetoriapot.github.io/smoke-archive/)と[公開リポジトリ](https://github.com/Tetoriapot/smoke-archive)を使用します。`.github/workflows/pages.yml`で、`main`へのpush時に依存関係のインストール、lint、テスト、型検査、本番ビルドを行い、成功した`dist/`を配信します。GitHubのSettings → Pages → SourceはGitHub Actionsを選択します。Actions画面から手動実行もできます。

`dist/`の内容をGitHub Pagesなどの静的サーバーに配置できます。Viteの`base`は`./`、画面の切り替えはハッシュURLを使うため、リポジトリ名を含むサブパスや詳細ページの再読み込みに対応します。サーバーでのURL書き換えは不要です。`index.html`をファイルとして直接開くのではなく、HTTPサーバーから配信してください。

Sitesの配信先は[SMOKE ARCHIVE](https://smoke-archive.tetoriapot.chatgpt.site)です。アクセス範囲は所有者本人に限定しています。配信設定は`.openai/hosting.json`で管理します。

ローカル版・Sites版・GitHub Pages版はURLが異なるため、ブラウザー内の設定帳やお気に入りは共有されません。人物設定は移行元でJSONまたはMarkdownを書き出し、移行先の設定帳で読み込むと移せます。お気に入りと表示モードは移行先で設定してください。今回の更新先はGitHub Pagesです。Sites版の内容は自動では更新されません。

## ディレクトリ

| パス | 用途 |
| --- | --- |
| `src/pages/` | 図鑑、詳細、逆引き、所作、設定帳、比較、出典 |
| `src/components/` | カード、ダイアログ、独自SVG |
| `src/data/` | ローカルJSONと出典、データ整合性テスト |
| `src/lib/` | 検索、逆引き、保存、入出力とテスト |
| `src/types.ts` | データ型 |
| `src/styles.css` | Tailwindの読み込みと画面スタイル |
| `src/theme.css` | ライトモードの配色 |
| `src/data/updates.json` | 日付・バージョン・変更点を含む更新履歴 |
| `src/data/help.json` | Helpの操作説明 |
| `docs/DATA_GUIDE.md` | 資料を追加する手順 |

データを追加するときは[入力ガイド](docs/DATA_GUIDE.md)と[データ仕様](DATA_SCHEMA.md)を確認し、出典検証とテストを実施してください。

機能を更新するときは`src/data/updates.json`の先頭に実際の更新日・バージョン・変更点を追加し、`package.json`のバージョンを合わせます。更新履歴の日付と、資料の出典確認日は別に管理します。ヘルプは`src/data/help.json`、ライトモードの配色は`src/theme.css`で変更できます。ダークモードは`src/styles.css`の既存色を使います。
