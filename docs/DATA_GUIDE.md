# 資料の追加ガイド

1. 登録対象を決めます。ブランド全体、特定の製品、器具の型式を区別し、既存資料の日本語名・原語名・別名・ブランド名を調べて重複を避けます。
2. メーカーの発表、博物館の収蔵記録、原著研究などを読みます。出典の発行日と、今回の確認日を区別します。本文を確認できなかったURLを根拠にしません。
3. `src/data/`内の同じカテゴリーの項目を参考に、`Item`の全フィールドを用意します。出典のない情報を埋める必要はありません。文字情報は「未確認」、年は`null`、現行状況は`unknown`とします。
4. 確認できた記述ごとに出典IDを付けます。資料のどこで何を確認したかは、出典の`scope`に記載します。味・香りや性能の宣伝上の評価は`attributed`にします。
5. 人物像やステレオタイプは`creative`へ分けます。「日本で一般的」「誰でもこう感じる」といった評判を根拠なく事実にしません。作品名や登場人物との関連も、実際に確認した出典がある場合だけ記載します。
6. 年代を点検します。創業年、商標登録年、設計年、特許年を、製品の発売年として扱わないでください。終売日・製造中止日も区別します。詳細は`DATA_SCHEMA.md`を参照してください。
7. 固定ID、関連ID、検索タグ、人物条件、配色を設定します。人物条件は`src/constants.ts`にある値を使います。配色は創作案であることを維持します。
8. 新しいJSONファイルを使う場合は`src/data/index.ts`へ追加します。次の検査を実行し、詳細画面、検索、逆引き、比較を実際に確認します。

```sh
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

日本語は出典と仕様を確認してからyomiyasuで推敲します。数値、固有名詞、条件、断定の強さを変えないでください。画像を追加する場合は、再利用できる権利とライセンスを確認して記録します。購入リンクや未成年者への訴求は追加しません。

現在の48件は、出典を確認できる範囲から選んでいます。100件に合わせるための重複登録や、未確認情報の補作は行いません。追加後はREADMEとTASKSに件数・検証結果を反映してください。
